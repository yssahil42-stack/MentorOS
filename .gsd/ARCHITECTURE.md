## Overview

MentorOS is an AI-powered workspace platform with role-based onboarding (Student, Freelancer, Developer, Job Seeker). It follows a monorepo architecture with a React/TypeScript frontend and Python/FastAPI backend, sharing types through a shared package.

## Components

### Frontend (1/apps/web)

**Purpose:** React SPA with role-based dashboards and AI-assisted workspace features
**Location:** '1/apps/web/src/'

| Directory | Purpose |
|-----------|---------|
| 'app/' | App-level providers, routing setup |
| 'components/' | Feature components (ai, calendar, charts, kanban, layout, providers, three, ui) |
| 'hooks/' | Custom React hooks |
| 'layouts/' | Page layouts (dashboard, auth, public) |
| 'lib/' | Utilities, API client, constants |
| 'pages/' | Route pages by role (auth, dashboard, developer, freelancer, job-seeker, onboarding, profile, public, settings, student) |
| 'routes/' | TanStack Router route definitions |
| 'store/' | Zustand state stores |
| 'styles/' | Global styles, Tailwind config |
| 'types/' | Frontend-specific type extensions |
| 'utils/' | Helper functions |

**Dependencies:** @mentoros/ui, @mentoros/shared-types, @mentoros/config, @tanstack/react-router, @tanstack/react-query, zustand, radix-ui, tailwindcss

**Dependents:** None (leaf node)

### Shared Packages (1/packages/)

| Package | Purpose | Location |

### Backend (backend/)

**Purpose:** FastAPI REST API with JWT authentication, role-based access, and AI integrations
**Location:** 'backend/app/'

| Module | Purpose |
|--------|---------|
| 'main.py' | FastAPI app factory, middleware, router registration, health checks |
| 'config.py' | Pydantic settings management (env vars, CORS, secrets, DB URL) |
| 'database.py' | SQLAlchemy engine, session factory, Base declarative |
| 'models.py' | SQLAlchemy ORM models (User, Project, Task, Milestone, CalendarEvent, Note, Goal, ContentItem, Invoice, RevokedToken) |
| 'schemas.py' | Pydantic request/response schemas |
| 'auth.py' | JWT auth, password hashing, Google OAuth, role-based dependencies |
| 'ownership.py' | Resource ownership validation utilities |
| 'rate_limit.py' | Rate limiting middleware |
| 'seed.py' | Database seeding for demo/development |
| 'routers/' | API route modules |

**API Routers (all under /api/v1):**
- 'auth.py' - Login, register, refresh, logout, me, Google OAuth
- 'tasks.py' - CRUD for tasks with role filtering
- 'projects.py' - CRUD for projects with role filtering
- 'calendar.py' - Calendar events CRUD
- 'notes.py' - Notes CRUD
- 'dashboard.py' - Dashboard aggregates, stats
- 'ai.py' - AI proposals (study_plan, work_plan, build_plan, job_search_plan, roadmap, task_breakdown, code_review, documentation)
- 'invoices.py' - Invoice management for freelancers
- 'git.py' - Git integration endpoints

**Dependencies:** FastAPI, SQLAlchemy, Pydantic, python-jose, passlib, httpx, google-auth, python-multipart

**Dependents:** Frontend via REST API

## Conventions

- **Naming:** PascalCase for components/types, camelCase for functions/variables, kebab-case for files
- **Structure:** Feature-based organization in frontend, module-based in backend
- **Testing:** Vitest (frontend), pytest (backend)
- **API:** RESTful with /api/v1 prefix, consistent error format
- **Auth:** JWT in httpOnly cookies, role-based access control
- **State:** Server state via TanStack Query, client state via Zustand
